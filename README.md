# Retail Sales Analytics Dashboard- Stephan UK

## Project Overview

This project demonstrates an end-to-end Business Intelligence solution built in Power BI using a retail sales dataset. The objective was to transform raw transactional data into an interactive executive dashboard that helps business stakeholders monitor sales performance, customer behavior, product performance, and return trends.

The project covers the complete analytics workflow, including data cleaning, data modeling, DAX calculations, dashboard design, and business insight generation.

# Business Problem

Retail businesses generate thousands of transactions every day, making it difficult for management to quickly answer questions such as:

- Which countries generate the highest revenue?
- How are sales changing over time?
- Which products contribute the most revenue?
- Who are the most valuable customers?
- How many customers make repeat purchases?
- Which products have the highest return rates?

This dashboard was designed to answer these questions through an interactive and easy-to-use reporting solution.

# Project Objectives

- Clean and transform raw retail transaction data
- Build an optimized Power BI data model
- Create reusable DAX measures
- Develop an executive dashboard for decision-makers
- Deliver meaningful business insights through interactive visualizations

# Dataset

**Dataset:** Online Retail Transaction Dataset

The dataset contains retail sales transactions including:

- Orders
- Customers
- Products
- Countries
- Revenue
- Quantity Sold
- Returns

The data was cleaned and transformed using Power Query before building the analytical model.
